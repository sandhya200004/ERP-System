# Public Assets

## Logo Setup

Please save the **TriVerse Solutions logo** image as:
```
triverse-logo.png
```

The logo should be:
- PNG format with transparent background (recommended)
- Approximately 400x150 pixels or similar aspect ratio
- The actual TriVerse Solutions logo from your branding materials

### Where it's used:
1. **Login Page** - Centered at the top of the login card
2. **Dashboard Sidebar** - Top left corner of the application
3. **Browser Tab** - As the favicon

### Steps to add the logo:
1. Save your TriVerse Solutions logo image to this directory
2. Name it exactly: `triverse-logo.png`
3. The app will automatically display it

If the logo file is missing, the app will show a broken image icon until you add it.
